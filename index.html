1 CAPA 1: RED — Primera barrera contra ataques

🔒

Cloudflare WAF (Web Application Firewall)

¿Qué hace? Filtra todo el tráfico antes de que llegue a tu servidor. Bloquea automáticamente:

❌ SQL Injection (inyectar código en formularios)

❌ XSS (inyectar scripts maliciosos)

❌ bots y scrapers automáticos

❌ IPs sospechosas y blacklists

🛡️

DDoS Protection

¿Qué hace? Evita que tu app se caiga por ataques de denegación de servicio:

❌ Bloquea miles de requests falsos por segundo

❌ Absorbe ataques de 100+ Gbps

❌ Mantiene la app online 24/7

✅ Cloudflare tiene la red más grande del mundo

⏱️

Rate Limiting

¿Qué hace? Limita cuántas peticiones puede hacer cada usuario/IP:

📱 Login: máximo 5 intentos/hora

🔑 OTP: máximo 3 envíos/minuto

💳 Pagos: máximo 10 transacciones/hora

🚨 Bloqueo automático 30 min si excede

🌐

SSL/TLS 1.3 Automático

¿Qué hace? Encripta toda la comunicación entre app y servidor:

🔒 Datos viajan encriptados (no se pueden leer)

⏱️ Handshake 30% más rápido que TLS 1.2

🔑 Perfect Forward Secrecy (keys únicas por sesión)

✅ Imposible interceptar pagos o datos

2 CAPA 2: APLICACIÓN — Control de quién entra y qué hace

📱

OTP por SMS (Sin contraseñas)

¿Qué hace? Envía un código de 5 dígitos al celular. Sin contraseñas que hackear:

📱 Usuario ingresa celular → recibe SMS

🔑 Código expira en 5 minutos

🚫 Máximo 3 intentos → bloqueo 30 min

✅ Nadie puede entrar sin tu celular

🔑

JWT + Refresh Tokens

¿Qué hace? Tokens de sesión que expiran y se renuevan automáticamente:

⏱️ Access Token: expira en 15 minutos

🔄 Refresh Token: expira en 7 días

🔐 Tokens firmados digitalmente (no se pueden falsificar)

🚫 Si roban token, expira rápido

👥

RBAC (Control por Roles)

¿Qué hace? Cada usuario solo puede ver y hacer lo que le corresponde:

👤 Cliente: solo ve sus propios fletes

🚛 Conductor: solo ve viajes asignados

🛡️ Admin: ve todo pero no accede a pagos directamente

❌ Un conductor NUNCA puede ver datos de otro cliente

✅

Input Validation + CORS

¿Qué hace? Valida y limpia todo lo que el usuario envía:

🔍 Valida formatos (email, teléfono, monto)

🧹 Limpia caracteres peligrosos (script, SQL)

🌐 CORS: solo acepta requests de tu app

🚫 Rechaza peticiones de dominios desconocidos

3 CAPA 3: DATOS — Encriptación de información sensible

🔐

AES-256 (Datos en reposo)

¿Qué hace? Encripta datos guardados en la base de datos:

👤 Datos personales encriptados

💳 Información de pagos tokenizada

📄 Documentos encriptados en almacenamiento

📍 Historial GPS encriptado

🔑 Misma encriptación que bancos y militares

🔒

TLS 1.3 (Datos en tránsito)

¿Qué hace? Encripta datos mientras viajan por internet:

📱 Datos del celular → servidor van encriptados

💳 Número de tarjeta NUNCA se envía sin encriptar

📍 Ubicación GPS se encripta al enviar

⚡ 30% más rápido que versiones anteriores

🗄️

Google Secret Manager

¿Qué hace? Almacena API keys y contraseñas de servicios externos:

🔑 API key de Libélula (pagos) → protegida

🔑 API key de Google Maps → protegida

🔑 API key de OpenAI → protegida

❌ NUNCA se guardan en código fuente

✅ Se rotan automáticamente cada 90 días

💳

Tokenización de Pagos

¿Qué hace? NUNCA guardamos datos de tarjeta de crédito:

⏰ Cuándo (timestamp exacto)

🔒 Los logs NO se pueden borrar (inmutables)

📅 Se guardan 2+ años para auditoría
